## Project Description
This project shows how I used different Java classes to create different Toyota vehicles. The project uses nested classes, wrapper classes, inheritance, and polymorphism. Basically, the different classes work together to show how Java can use information from one class in another and how different vehicle types can work together in the same program.
## Programming Concepts and Tools

This project demonstrates the following Java programming concepts:

- Nested classes
- Wrapper classes
- Inheritance
- Polymorphism
- Classes and objects
- Constructors
- Methods
- Method overriding
- Encapsulation

The project was developed using Java.

## Project Files

- `Main.java` – Contains the main method and runs the program.
- `Automobile.java` – Defines the Automobile class.
- `Toyota.java` – Defines the Toyota class.
- `Corolla.java` – Defines the Corolla class.
- `Highlander.java` – Defines the Highlander class.
- `Tundra.java` – Defines the Tundra class.

## Expected Input
The program produces output demonstrating the behavior of the
different vehicle objects and the use of inheritance and polymorphism.
